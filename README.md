CyberX Family Safety

CyberX is a family safety and cybersecurity education project.

Project Components

- "frontend/" — Parent dashboard
- "backend/" — Secure API and device pairing
- "android/" — Android companion application

Security

Live screen sharing must require explicit consent on the child's device, a visible notification, and an immediate stop control.

Project Status

Source files and build configuration are being prepared. The project is not yet verified as a working application.
